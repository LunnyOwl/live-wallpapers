# 🖼 Живые обои

Обои на рабочий стол, которые двигаются: лес со сменой дня и ночи, муравейник, который растёт целую неделю, аквариум с рыбками (в него можно играть!), ретро-часы, ночной город, камин, пакман, тетрис и ещё больше 25 штук.

**Работают на Mac и на Windows. Интернет не нужен.**

🍂 **Времена года:** зимой на обоях идёт снег, осенью летят листья, весной распускаются цветы, а на Новый год появляются гирлянды. Всё переключается само по дате.

## ⬇️ Скачать

**[Скачать ОБОИ.zip](https://github.com/LunnyOwl/live-wallpapers/raw/main/ОБОИ.zip)** (Mac и Windows в одном архиве)

🔒 Архив закрыт паролем. **Пароль даёт автор.** Подробная инструкция лежит внутри архива, в файле `Инструкция.txt`.

## Как поставить (коротко)

**Mac**
1. Распакуй архив двойным щелчком и введи пароль. Папку `ОБОИ` положи в «Документы».
2. Поставь Python с [python.org/downloads/macos](https://www.python.org/downloads/macos/).
3. Нажми на «1. Установить» правой кнопкой → «Открыть» → «Открыть».
4. Чтобы поменять обои, открой «2. Выбрать обои».

**Windows 10 / 11**
1. Нажми на архив правой кнопкой → «Извлечь всё…» и введи пароль. Папку `ОБОИ` положи в «Документы».
2. Поставь бесплатную программу **Lively Wallpaper** из Microsoft Store.
3. В Lively нажми «+» → «Browse» и выбери файл обоев из папки `ОБОИ`.
